## Recommended Demo Order
1. Organisation creates and manages hiring pipeline
2. Student applies and progresses
3. Organisation schedules interview and issues offer
4. Student responds to offer
5. Mentor flow: availability, session booking/approval, join call
6. College flow: student visibility, placement tracking, reports

This order tells one complete story from opportunity creation to mentoring and placement insights.

---

## Common Demo Setup
1. Open app and keep one browser profile per role (or use incognito windows).
2. Keep one tab for each role login to quickly switch context.
3. Use Dashboard as the home for each role.
4. If data looks stale, refresh once (realtime is enabled, but refresh helps during live demos).

## Journey 1: Organisation Demo

## Login
- Sign in with Organisation credentials.
- Land on organisation dashboard.

## What to Showcase
1. Dashboard overview
- Show Active Listings, Applications, Interviews, Offers Accepted.
- Explain this is live pipeline visibility.

2. Post Job
- Go to Post Job.
- Create a job with role, description, skills, and details.
- Explain structured job posting and downstream applicant tracking.

3. My Listings
- Open Listings.
- Show created jobs and status management.

4. Applications pipeline
- Open Applications.
- Move candidates through stages (pending, assessment, interview, selected, rejected).
- Explain status control and decision traceability.

5. Assessments
- Open Assessments.
- Show assignment configuration and evaluation flow.

6. Interviews
- Open Interviews.
- Schedule interview from selected candidates.
- Explain interview scheduling and tracking.

7. Offers
- Open Offers.
- Issue offer letter.
- Explain that student response updates org-side analytics.

8. Analytics
- Open Analytics.
- Show stage-level counts and hiring outcomes.

## Demo Talking Point
Organisation gets an integrated ATS-like workflow from posting to offer acceptance with live dashboard feedback.

## Journey 2: Student Demo

## Login
- Sign in with Student credentials.
- Land on student dashboard.

## What to Showcase
1. Dashboard cards
- Show applications, interviews, offers, and quick actions.

2. Browse Jobs
- Open Browse Jobs.
- Open job detail and submit application.
- Explain simple and focused candidate experience.

3. My Applications
- Open My Applications.
- Show status progression as org updates pipeline.

4. Assessments
- Open Assessments.
- Show assigned assessments and attempt flow.

5. Interviews
- Open Interviews.
- Show scheduled interviews and details.

6. Offers
- Open Offers.
- Show issued offers and accept/reject action.
- Explain accepted offer is reflected in organisation analytics.

7. Resume Tailor
- Open Resume Tailor.
- Show optimization workflow and profile readiness support.

8. Find Mentors
- Open Find Mentors.
- Show mentor cards populated from available slots.

9. Book Mentor Session
- Click View and Book Session.
- Choose date and time slot.
- Submit booking.
- Open My Sessions and show pending/confirmed status.

10. Join Call
- For confirmed sessions, click Join Call.
- Explain session video room opens directly.

## Demo Talking Point
Student journey is unified across jobs, assessments, interviews, offers, and mentorship in one dashboard.

## Journey 3: Mentor Demo

## Login
- Sign in with Mentor credentials.
- Land on mentor dashboard.

## What to Showcase
1. Dashboard
- Show upcoming sessions, totals, and rating summary.

2. Availability
- Open Availability.
- Add weekday slots with start/end times.
- Explain this controls discoverability in student Find Mentors.

3. Sessions
- Open My Sessions.
- Show incoming booking requests.
- Approve (confirm) session.
- Show Join Call action for confirmed session.
- If needed, refresh link and join again.

4. Reviews
- Open Reviews and show feedback visibility.

## Demo Talking Point
Mentor can manage supply (availability), demand (requests), and delivery (live sessions) end-to-end.

## Cross-Role Showcase Scenario (Best Client Demo)
1. Organisation posts job.
2. Student applies.
3. Organisation moves student to interview and schedules interview.
4. Organisation issues offer.
5. Student accepts offer.
6. Return to Organisation Analytics and College dashboards to show updated outcomes.
7. Student books mentor session.
8. Mentor confirms session and both join call.

This proves the platform is not static pages; it is a connected multi-actor workflow.

---

## Quick Troubleshooting During Live Demo
1. If list seems empty, refresh once and reopen page.
2. If switching roles, ensure correct account is signed in.
3. For sessions, confirm mentor has availability slots and session status is confirmed to show Join Call.
4. If any action fails, re-open the same module and retry once.
